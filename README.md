# MarkWord 線上轉換工具使用說明文件

歡迎使用 MarkWord 線上轉換工具。本工具是一個完全運行於瀏覽器端的純前端（Client-side）單頁應用程式（SPA），無需安裝任何軟體或上傳資料至後端伺服器，確保您的文件隱私與資訊安全。

---

## 系統架構與模式切換

本系統已將三大轉換核心整合至單一檔案 [index.html](file:///d:/Antigravity/Markdown%20to%20Word/index.html) 中。您可以透過頁面頂部的導覽列在三種模式之間瞬間切換，且**共用同一份編輯區內容**，無需重新整理頁面：
1. **Markdown 轉 Word**（網址 `#word`）：適合需要將一般文件、含有簡易符號的報告轉換為 Word 格式（`.doc`）的場景。
2. **Markdown 轉 HTML**（網址 `#html`）：適合內容包含複雜數學公式，或需要轉換為網頁程式碼、發布為獨立網頁（`.html`）的場景。
3. **Markdown 轉 PDF**（網址 `#pdf`）：適合需要將 Markdown 文件直接轉換為標準可攜式 PDF 檔案（`.pdf`）的場景。

> **離線單檔使用說明**：若您處於無網路或高機密環境，只需從 GitHub 下載單一檔案 `index.html`，直接以瀏覽器開啟即可使用全部三種轉換功能。舊版分頁網址（`markdown-to-html.html` 與 `markdown-to-pdf.html`）已設為自動重新導向 stub，確保既有書籤正常運作。

## 核心通用功能

* **瀏覽器本地自動暫存（LocalStorage）**：您在編輯區輸入的文字與自訂檔案名稱會自動儲存於瀏覽器本地端。重新整理網頁或切換模式皆不會遺失進度。
* **支援檔案拖放匯入（Drag & Drop）**：除了點擊「匯入 Markdown 檔案」按鈕外，您也可以直接將電腦中的 `.md` 或 `.txt` 檔案拖曳至左側編輯區放開，系統將自動載入內容並帶入檔案名稱。
* **雙欄比例同步捲動**：捲動左側 Markdown 編輯區時，右側預覽區會依照文章比例自動同步捲動，方便長篇文件對照修改。
* **視窗寬度自由拖曳（Splitter）**：按住編輯區與預覽區中間的垂直分割線左右拖曳，可自由調整雙欄寬度比例。
* **DOMPurify 安全防禦**：內建 HTML 淨化與字元轉義機制，防範惡意跨站腳本（XSS）注入風險。

## 功能一：Markdown 轉 Word (`#word`)

本功能針對 Microsoft Word 的 HTML 檔案匯入器進行最佳化，將 Markdown 文件導出為高相容性的 Word 文件（`.doc` 格式）。

### 1. 操作步驟
* **輸入或匯入內容**：於左側編輯器輸入 Markdown，或拖放檔案匯入。
* **設定輸出檔名**：於右側控制列輸入框設定檔名（預設為「我的轉換文件」）。
* **導出 Word**：點選「導出為 Word 檔案 (.doc)」按鈕即可下載。

### 2. 技術特色
* **視覺渲染層保留機制**：為避免 Microsoft Word 開啟 HTML 文件時因不支援標準 MathML 而產生公式文字重複或結構破碎的問題，系統在導出前會自動剔除 `.katex-mathml` 節點，僅保留 `.katex-html` 視覺渲染層，以 Unicode 特殊字元呈現符號。
* **特殊字元防亂碼技術**：導出前自動將所有非 ASCII 字元編碼為 HTML 實體字元（HTML Entities），確保在不同作業系統與各版本 Word 中開啟皆不會產生亂碼。

## 功能二：Markdown 轉 HTML (`#html`)

本功能用於將 Markdown 語法轉換為乾淨的網頁原始碼，並支援即時預覽與包含 KaTeX CDN 的獨立網頁導出。

### 1. 操作步驟
* **切換預覽與原始碼**：點選右側面板頂部的「即時預覽」或「HTML 原始碼」頁籤，可隨時檢視渲染結果與乾淨的 HTML 標籤。
* **一鍵複製**：點選「複製 HTML 原始碼」按鈕，可直接將 HTML 代碼複製到剪貼簿。
* **導出獨立網頁**：點選「導出為 HTML 檔案 (.html)」，系統會自動打包一個包含完整響應式樣式表與 KaTeX 公式渲染腳本的獨立 HTML 檔案。

---

## 功能三：Markdown 轉 PDF (`#pdf`)

本功能基於瀏覽器內建的列印引擎與 `@media print` 專屬樣式表，直接將渲染成果導出為向量級且支援文字選取複製的 PDF 檔案。

### 1. 操作步驟
* **觸發列印匯出**：點選「導出為 PDF 檔案 (.pdf)」按鈕，系統會自動將輸出檔名套用至列印標題並開啟系統列印視窗。
* **最佳化列印設定**：
  * **目的地**：選擇**「另存為 PDF」**。
  * **背景圖形**：展開「更多設定」，**勾選「背景圖形」**以保留引用區塊邊框、表格斑馬紋與程式碼底色。
  * **頁首和頁尾**：**取消勾選「頁首和頁尾」**，移除邊緣網址與列印日期。
