# MarkWord 線上轉換工具（Word / HTML / PDF 三合一單頁架構）

歡迎使用 **MarkWord** 線上轉換工具。本專案是一個完全運行於瀏覽器端的純前端（Client-side）單頁應用程式（SPA），專為解決 AI 工具（ChatGPT、Claude、Gemini 等）輸出之 Markdown 內容轉換需求而設計。

所有文件解析與格式轉換 100% 在您的電腦瀏覽器本地執行，無需安裝任何軟體，亦不會將任何資料上傳至後端伺服器，確保最高等級的隱私與資訊安全。

---

## 二、 複製到其他電腦或「完全無網路（離線環境）」使用方式

本專案已將所有解析引擎（`marked.umd.js`、`purify.min.js`、`katex.min.js`、`katex.min.css` 以及 20 個 `.woff2` 數學符號專用字型檔）完整內建於倉庫的 `vendor/` 資料夾中，完全不依賴外部網路 CDN。

若您需要在**沒有網路的隔離電腦（Air-Gapped Environment）**或處理高機密文件時使用，請依下列步驟操作：

### 方法 1：從 GitHub 下載完整離線包
1. 點擊本頁面右上角的綠色按鈕 **「<> Code」**，選擇 **「Download ZIP」**。
2. 將下載的 `.zip` 壓縮檔透過隨身碟（USB）或內部網路複製到目標電腦並解壓縮。
3. 在無網路電腦上，直接雙擊開啟資料夾內的 **`index.html`**，即可 100% 離線使用全部三種轉換功能。

### 方法 2：從現有資料夾複製核心檔案
若您已下載過本專案，只需將以下 **2 個項目** 放在同一個資料夾內一併複製到其他電腦即可：
1. **`index.html`**（三合一主程式檔案）
2. **`vendor/`**（離線解析引擎與數學字型資料夾）

```text
您的資料夾/
├── index.html          <-- 雙擊此檔案直接以瀏覽器開啟
└── vendor/             <-- 必須與 index.html 放在同一個目錄下
    ├── marked.umd.js
    ├── purify.min.js
    ├── katex.min.js
    ├── auto-render.min.js
    ├── katex.min.css
    └── fonts/          (內含 20 個 KaTeX .woff2 離線數學字型檔)
```

## 三、 核心體驗與安全功能

1. **三合一單頁無縫切換（SPA）**：透過頂部導覽列可一鍵在「轉 Word」、「轉 HTML」、「轉 PDF」三種模式間瞬間切換，共用同一份編輯區內容，無需重新載入網頁。
2. **AI 剪貼簿雙向快捷按鈕**：
   * **貼上剪貼簿**：位於左側編輯區上方，一鍵將從 AI 複製的 Markdown 內容貼入並完成渲染。
   * **複製排版內容**：位於右側預覽區上方，可將渲染後的富文本（含表格、粗體、標題與符號）直接複製到剪貼簿，免下載檔案即可直接貼入開啟中的 Microsoft Word、Google Docs 或電子郵件中。
3. **LaTeX 數學公式防誤拆保護**：內建公式預先保護機制，防止同一行公式內的多重下底線（如 `$x_1 + x_2 = y_n$`）被 Markdown 解析器誤判為斜體，並完整保留矩陣換行語法 `\\`。
4. **防誤刪「復原內容」機制與本地自動暫存**：
   * 編輯內容與自訂檔名會即時自動暫存於瀏覽器 `localStorage`，重新整理網頁不會遺失進度。
   * 當執行「清空內容」、「載入預設範例」、「貼上剪貼簿」或「匯入檔案」覆蓋現有內容時，工具列會自動浮現 **「復原內容」** 按鈕，一鍵即可還原。
5. **支援檔案拖放匯入（Drag & Drop）**：可直接將電腦中的 `.md`、`.markdown` 或 `.txt` 檔案拖曳至左側編輯區放開匯入，並自動帶入檔案名稱。
6. **雙欄比例同步捲動與視窗寬度拖曳**：左右視窗支援長文捲動比例同步；按住中間垂直分割線（Splitter）左右拖曳，可自由調整編輯區與預覽區的寬度比例。
7. **資訊安全防禦（XSS Protection）**：內建 `DOMPurify` 安全過濾器與 HTML 實體轉義機制，杜絕惡意跨站腳本注入風險。

## 四、 三大轉換模式詳細說明

### 1. Markdown 轉 Word (`#word`)
* **適用場景**：一般行政報告、純文字文件與含基礎符號之教材。
* **技術特色**：
  * **標準 A4 整頁模式開啟**：內嵌 Microsoft Office XML `<w:View>Print</w:View>` 與 A4 版面配置宣告，使 Word 開啟 `.doc` 檔案時直接呈現標準 A4 整頁模式。
  * **視覺渲染層保留機制**：導出前自動剔除 `.katex-mathml` 節點，僅保留 `.katex-html` 視覺渲染層，以 Unicode 特殊字元呈現符號，彻底解決 Word 不支援 HTML MathML 導致公式文字重複顯示的問題。
  * **全字元防亂碼編碼**：自動將所有非 ASCII 字元轉為 HTML 實體（HTML Entities），確保在任何語言版本的 Windows / macOS Word 中開啟皆不會亂碼。

### 2. Markdown 轉 HTML (`#html`)
* **適用場景**：包含複雜科學與數學公式的文件展示、部落格文章發布或取得乾淨網頁原始碼。
* **操作方式**：
  * 點選右側頂部頁籤可切換檢視 **「即時預覽」** 與 **「HTML 原始碼」**（純淨結構片段，適合貼入 CMS 後台）。
  * 點選右上角 **「導出為 HTML 檔案」**，可下載包含完整響應式樣式表與已渲染公式結構的獨立 `.html` 網頁檔。

### 3. Markdown 轉 PDF (`#pdf`)
* **適用場景**：需要產出向量級清晰數學公式與跨平台固定版面的歸檔文件。
* **最佳化列印設定**：
  1. 點選 **「導出為 PDF 檔案」** 開啟系統列印對話框（系統會自動將您設定的檔名套用為 PDF 預設存檔名稱）。
  2. 將「目的地」設為 **「另存為 PDF」**。
  3. 展開「更多設定」，**勾選「背景圖形」**（保留表格斑馬紋、引用區塊左框線與程式碼區塊底色），並建議**取消勾選「頁首和頁尾」**。
