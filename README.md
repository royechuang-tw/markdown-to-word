# MarkWord 線上轉換工具使用說明文件

歡迎使用 MarkWord 線上轉換工具。本工具是一個完全運行於瀏覽器端的純前端（Client-side）解決方案，無需安裝任何軟體或上傳資料至後端伺服器，確保您的文件隱私與資訊安全。

---

## 系統架構與頁面切換

本系統提供三大核心轉換功能，您可以透過頁面頂部的導覽列在三個工具之間無縫切換：
1. **Markdown 轉 Word**（預設首頁 `index.html`）：適合需要將技術文件、含有數學公式的講義轉換為 Word 格式的場景。
2. **Markdown 轉 HTML**（`markdown-to-html.html`）：適合需要將 Markdown 轉換為網頁程式碼，或發布為獨立網頁的場景。
3. **Markdown 轉 PDF**（`markdown-to-pdf.html`）：適合需要將 Markdown 文件轉換為標準可攜式 PDF 檔案的場景。

---

## 功能一：Markdown 轉 Word (`index.html`)

本功能針對 Microsoft Word 的 HTML 相容性進行了深度最佳化，能夠將 Markdown 文件導出為相容性極高且支援數學公式原生渲染的 Word 文件（`.doc` 格式）。

### 1. 操作步驟
* **載入範例**：點選「載入預設範例」按鈕，可快速查看系統對特殊符號與複雜數學公式的轉換效果。
* **手動輸入或匯入**：直接在左側編輯器輸入 Markdown 內容，或點選「匯入 Markdown 檔案」讀取本機的 `.md` 或 `.txt` 檔案。
* **設定輸出檔名**：在右側控制列的「輸出檔案名稱」輸入框中設定導出的檔名（預設為「我的轉換文件」）。
* **導出 Word**：確認內容無誤後，點選「導出為 Word 檔案 (.doc)」按鈕，瀏覽器將自動下載該檔案。

### 2. 技術特色與最佳化機制
* **數學公式完美相容**：系統會自動將 LaTeX 公式（包含行內公式與區塊公式）透過內建機制轉換為 Word 原生支援的 MathML `<math>` 方程式物件。在 Microsoft Word 中開啟時，公式將以 Word 原生方程式格式呈現，可直接進行二次編輯。
* **防重複渲染機制**：為了解決傳統轉換工具在 Word 中會同時顯示公式圖形與 LaTeX 原始碼的 Bug，本系統在導出前會徹底過濾 KaTeX 的渲染殘留節點，僅保留標準 MathML 結構，確保排版乾淨。
* **特殊字元防亂碼技術**：中文、希臘字母、科學符號（如 $\pm$、$\alpha$、$\theta$ 等）在不同作業系統或 Word 版本中常因編碼衝突產生亂碼。本系統使用全域轉譯技術，在導出前將所有非 ASCII 字元編碼為 HTML 實體字元（HTML Entities），保證在任何版本的 Word 中開啟皆能 100% 正確顯示。

---

## 功能二：Markdown 轉 HTML (`markdown-to-html.html`)

本功能用於將 Markdown 語法轉換為乾淨的網頁原始碼，並支援即時預覽與包含 KaTeX CDN 的獨立網頁導出。

### 1. 操作步驟
* **編輯與即時預覽**：在左側編輯器修改內容，右側預覽面板會透過 Marked.js 與 KaTeX 即時渲染出最終的視覺效果。
* **查看 HTML 原始碼**：點選右側面板頂部的「HTML 原始碼」頁籤，可即時檢視轉換後的 HTML 標籤。
* **一鍵複製**：點選「複製 HTML 原始碼」按鈕，可直接將產生的 HTML 代碼複製到剪貼簿。
* **導出獨立網頁**：設定好輸出檔名後，點選「導出為 HTML 檔案 (.html)」。系統會自動打包一個包含完整樣式表與 KaTeX 自動公式渲染腳本的單一 HTML 檔案。

---

## 功能三：Markdown 轉 PDF (`markdown-to-pdf.html`)

本功能基於瀏覽器內建的列印引擎，配合列印專屬 CSS 樣式表，可直接將 Markdown 渲染後的成果導出為高品質、向量化且支援文字選取複製的 PDF 檔案。

### 1. 操作步驟
* **編輯與即時預覽**：在左側編輯器輸入內容，右側可即時預覽公式與 Markdown 排版樣式。
* **觸發列印匯出**：點選右側的「導出為 PDF 檔案 (.pdf)」按鈕。系統將自動修改網頁標題（做為 PDF 的預設檔案名稱）並彈出系統列印對話框。
* **最佳化列印設定**：
  * **目的地**：務必選擇**「另存為 PDF」**。
  * **背景圖形**：展開「更多設定」，並**勾選「背景圖形」**以完整保留引用區塊的紫條左框線、背景色與表格斑馬紋。
  * **頁首和頁尾**：**取消勾選「頁首和頁尾」**，即可移除 PDF 頁面邊緣產生的網址、日期與預設頁碼，使產出文件乾淨專業。

### 2. 技術特色
* **向量級公式排版**：採用此方案導出的 PDF 檔案，其 KaTeX 公式為 SVG 向量物件。相較於將 HTML 轉為圖片再打包 PDF 的工具，本工具導出的 PDF 公式即使放大數十倍亦維持完美清晰。
* **文字支援複製選取**：產出的 PDF 檔案保留標準文字編碼，可直接用 PDF 閱讀器選取、搜尋與複製文件內的任何中英文內容。

## 系統需求與注意事項

1. **瀏覽器相容性**：支援 Chrome、Edge、Safari、Firefox 等主流現代瀏覽器。
2. **開啟導出檔案**：
   * 導出的 Word 檔案為高相容性的 HTML-based Word 格式，請直接使用 Microsoft Word 開啟。
   * 首次開啟時，Word 可能會提示「受保護的檢視」，請點選「啟用編輯」即可正常閱讀與修改。
   * 導出的 HTML 與 PDF 檔案均可直接雙擊開啟。
3. **無網路環境限制**：本工具主程式完全在瀏覽器端運行，不依賴後端伺服器；惟導出的 HTML 檔案若需渲染數學公式，開啟該 HTML 時電腦需保持網路連線以載入 KaTeX CDN。
